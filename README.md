# MySpace Retro 🖤

Eu nunca tive um MySpace. Mesmo assim, sempre fui fascinado por aquelas páginas de perfil: glitter, música tocando sozinha, fundo estourado e um "Top 8" que virava assunto de briga.

Este projeto é a minha tentativa de recriar essa estética emo/Y2K do zero, só com HTML e CSS, sem frameworks e sem enrolação.

## 🌐 Dá uma olhada

👉 https://killvodka.github.io/myspace-retro/

## 📸 Sobre o projeto

Queria que a página parecesse um perfil de 2005, daqueles que a gente passava horas personalizando. Por isso ela tem:

- Layout de perfil no estilo clássico
- GIFs retrô por todo lado
- Background personalizado
- Toda a estética dos anos 2000

## 🛠️ Feito com

- HTML5
- CSS3
- Git
- GitHub Pages
